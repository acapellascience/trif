# timsrobot.com/clip: the words (branch clip-page)

**Awaiting Tim.** The page the iPhone app opens in Safari to add a site's icon to the Home Screen
(site/src/clip.js, `CLIP_WORDS`). It shows one line at a time.

| Where | Words |
|---|---|
| Tab title | Add to Home Screen · TRIF |
| Heading | Add to Home Screen |
| The icon is good (Safari is asking to download it) | Safari asks to download a profile: tap Allow. Then open Settings, tap Profile Downloaded near the top, and Install. |
| Button under it (if they tapped Ignore) | Download it again |
| Opened without an icon in the address | Open this page from TRIF on your iPhone: the … menu, then Add to Home Screen. |
| The address holds something that isn't a TRIF icon | This link doesn’t hold a TRIF Home Screen icon, so nothing was made. |
