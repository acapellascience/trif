TRIF {{VERSION}} beta (Chrome, Mac)
=============================

TRIF (Tim's Robot Internet Fixer) lets your coding agent (Claude Code or Codex) customize websites for you. It comes with mods for
Google, X, Amazon and Instagram, already on; everywhere else it stays off until you turn it on.

You need
- Google Chrome, up to date (Chrome menu > About Google Chrome).
- Claude Code (https://claude.com/claude-code) or Codex (https://github.com/openai/codex) installed.
  (Or an open model through Codex, experimental: https://github.com/acapellascience/trif#open-models-experimental)
- Node 18 or newer. Check in Terminal with:  node --version
  If that says "command not found", install it from https://nodejs.org (the LTS button).

Already have an earlier beta? (It was called WebMods before version 0.2.0.)
  Do step 2 again from this folder (your mods and settings are kept; WebMods' folder ~/.webmods moves
  to ~/.trif, leaving a link behind: don't delete ~/.webmods). Then in chrome://extensions, click the
  circular reload arrow on WebMods or TRIF. The TRIF panel tells you when there's an update and
  installs it with one click.

Install (about 2 minutes)
1. Open Chrome once if you haven't yet, so it has a profile.
2. Open Terminal and paste these two lines (change the path if this folder isn't in Downloads):

     cd ~/Downloads/trif-beta-chrome
     npx --yes --package ./trif-{{VERSION}}.tgz trif setup --browser chrome

   It prints a few lines saying what it set up, then a list of next steps (the ones below). You can
   ignore its note about PATH.

   Setup also opens a Finder window with a folder called "extension" selected, and Chrome's
   extensions page (chrome://extensions). Leave both open. Then it waits in Terminal, saying as each
   of the next steps gets done, until Chrome has TRIF and user scripts are on (Ctrl-C skips the wait).

3. On the chrome://extensions page that opened (or go there in Chrome), turn on "Developer mode"
   (top right).
4. Drag the "extension" folder from that Finder window onto the chrome://extensions page.
   TRIF appears in the list, and opens a "TRIF setup" tab. Leave the folder where it is: Chrome runs
   TRIF from it.
   (If dragging doesn't work: click "Load unpacked", press Cmd-Shift-G, press Cmd-V to paste the
   folder's path, which setup put on your clipboard, then press Return and click Select.)
5. On the TRIF setup tab that opened, click "Open TRIF’s Chrome settings" and turn on "Allow User
   Scripts".
6. Click the puzzle-piece button in Chrome's toolbar and pin TRIF.

Try it
- Visit google.com, x.com, amazon.com or instagram.com: the mods are already working. Click the TRIF
  button to open its side panel and see them; each has a switch, and a green light when it's running on
  the page you're on.
- On any other site, the side panel says "The robot is off." Click "Fix <site>", then
  describe the change you want ("hide the comments", "make it dark") and your agent writes a mod for it.
  The first time, it may ask you to log in to Claude: click Log in and follow the steps.

If something's wrong, click the gear in the TRIF panel, then "Report a problem". Or, if the panel
doesn't work at all, run this in Terminal: it opens the same form with your setup details filled in.

     ~/.trif/bin/trif report --open

Or go to https://timsrobot.com/report and describe it there.
